# 🫘 BrewDiary

A simple coffee brewing and tasting journal. Log every brew, rate it, and spot what you like best.

## Main Features
- Dashboard with total brews, average rating, favorite method and this week's count
- "Brews by Method" breakdown
- Log, edit and delete brews: bean, origin, roast, method, dose, water, time and a star rating
- Automatic brew ratio (e.g. 1:16)
- Search and filter by brewing method
- Data saved in your browser with LocalStorage
- Responsive design with modal forms and toast messages

## Technologies
HTML5, CSS3, Vanilla JavaScript, LocalStorage

## How to Run
Open `index.html` in any modern browser. No install or server needed.
